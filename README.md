# market-empire-releases
MARKET EMPIRE ist eine Supermarkt-Aufbausimulation im Stil von Anno. Starte mit einem kleinen Laden, gestalte deinen Markt, verwalte Waren, Personal und Kundenbedürfnisse. Eröffne neue Filialen, konkurriere mit anderen Spielern, gründe Einkaufsgenossenschaften und erschaffe dein eigenes Handelsimperium!
